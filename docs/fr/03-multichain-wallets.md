# 3. Multi-chaînes et multi-wallets

Le README mentionne les réseaux EVM, Solana et Bitcoin, le multi-chain et le multi-wallets. AppKit Core est présenté comme chain agnostic, ce qui permet de concevoir une interface commune tout en gardant des adaptateurs par réseau.

La DApp doit cependant afficher la chaîne active, normaliser les formats d’adresse et empêcher les signatures sur un réseau inattendu.
